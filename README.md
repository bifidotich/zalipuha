# zalipuha

Залипуха, залипуха –
Изолента, клей и слухи.
Вместо стройных классов – каша,
Глобальных переменных чаща.

Ты спасаешь в час полночный,
Код – лапша, но очень прочный.
Пусть тимлид седой вздыхает –
Залипуха процветает.

IF на IF, свистит, но едет,
Богу душу лишь предал.
Комментарий: «Трогать страшно».
И другому передал.

Вместо классов — словно ёлка:
Вся в игрушках из осколков,
Глобал-переменный снег,
Что не тает целый век.

Залипуха, ты — стихия,
Не поймут тебя святые
Дяди в чистых пиджаках
С architecture на устах.

Ты из кофе, скотча, мата,
И из пенопласта свята.
Обещали перепишут,
Только ты всё выше, выше.

Ты рождаешься под вечер,
Когда срок калечит плечи,
Из костыльного металла,
Лишь бы кнопка не отпала.

Пусть твердят, что ты – халтура,
Что страшна архитектура,
Но пока живет проект,
Ты – его святой скелет.

Восхвалим залипуху хором!
Слава вечным костылям!
Рефакторинг будет скоро.
Аминь, продакшен, по полям.
